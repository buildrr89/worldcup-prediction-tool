# Handoff Template

Copy this block into your final message at the end of a work session, filled in.
It lets the next tool (Claude Code, Codex, Antigravity, …) continue without
re-discovering context.

```markdown
## Handoff

**What changed:**
- (1–3 sentence summary of the work.)

**Files edited:**
- path/to/file — what and why

**Commands run:**
- `command` — what it did

**Validation result:**
- (Paste real output. State pass/fail honestly. If skipped, say so.)

**What is proven:**
- (Claims you actually verified.)

**What is NOT proven:**
- (Untested paths, assumptions, things left unverified.)

**Next recommended task:**
- (The single next task. Keep it scoped to one session.)

**Risks / notes:**
- (Anything the next agent should watch out for. New assumptions made.)
```
